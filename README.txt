Prescription Healthcare System — HTML, CSS and JavaScript version

Run locally:
1. Extract this folder.
2. Open index.html in your browser, or use VS Code Live Server.
3. No npm install or build command is required.

Files:
- index.html: page structure
- styles.css: styling copied from the supplied project
- app.js: page routing and demo interactions

This version uses plain HTML/CSS/JavaScript (no React, Vite, Express, or MongoDB).
Sample data is stored in browser localStorage. It is demo-only and not secure/shared.
To deploy on Vercel, import the GitHub repository and choose Other; leave Build Command empty and Output Directory as . (root).
